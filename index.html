Backpacks Mod Tutorial

Step-by-step guide to adding backpacks to your mod with datapacks and resourcepacks

Overview Create Datapack Create Resourcepack Example JSON Folder Structure

Overview

This tutorial will show you how to add backpacks to your mod using a datapack for definitions and a resourcepack for the models. Each backpack requires:

  • A JSON definition in the datapack
  • Models for worn backpacks (assets/<modid>/models/backpacks/)
  • Models for placed backpacks (assets/<modid>/models/backpacks/blocks/)

The Java record used for backpacks is already implemented in the mod. You can find a reference here.

Step 1: Create the Datapack

1. Create a folder called data/<modid>/backpacks/ in your mod or datapack directory.
2. Each backpack is defined as a JSON file in this folder.

Example path:

data/gbackpacks/backpacks/my_backpack.json

Each JSON file defines the backpack ID, translation key, GUI displacement/scale, and block collision shape.

Note: GUI displacement and scale will not work for versions over 26.1, will be re-added down the line when I figure out how to render blocks in a gui.

Step 2: Create the Resourcepack

1. Create a folder structure for your models:

assets/<modid>/models/backpacks/         ← worn backpacks
assets/<modid>/models/backpacks/blocks/  ← placed backpacks

2. Models must use the same name as your backpack JSON ID for consistency.
3. Place your .json model files here. For example: 

assets/gbackpacks/models/backpacks/my_backpack.json
assets/gbackpacks/models/backpacks/blocks/my_backpack.json

Step 3: Example JSON

Here is a sample backpack JSON:

{
  "id": "gbackpacks:backpacks/my_backpack",
  "translation_key": "backpack.gbackpacks.my_backpack",
  "gui_displacement": [0, 0],
  "gui_scale": 1.0,
  "block_collision_shape": [
    [5, 0, 6],
    [11, 9, 10]
  ]
}

Note: Collision coordinates are relative to the block facing north.

Note: "gui_displacement" and "gui_scale" are not available yet on versions over 26.1.

Folder Structure Summary

my_mod/ ├─ data/ │ └─ gbackpacks/ │ └─ backpacks/ │ └─ my_backpack.json └─ assets/ └─ gbackpacks/ └─ models/ ├─ backpacks/ │ └─ my_backpack.json └─ backpacks/blocks/ └─ my_backpack.json

Follow this structure to ensure your backpacks load correctly in-game.
